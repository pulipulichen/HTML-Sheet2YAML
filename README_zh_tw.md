# HTML-Sheet2YAML

[English](./README.md) | [繁體中文](./README_zh_tw.md)

輕量級純 HTML 工具，可在瀏覽器中直接將 Google Sheets、ODS、XLSX、CSV 資料轉換為 YAML。

## 線上展示

https://pulipulichen.github.io/HTML-Sheet2YAML/

## 示範 Google Sheet

可點擊畫面上的「試用示範 Google Sheet」，或開啟這份公開試算表：

https://docs.google.com/spreadsheets/d/1dOFyNqpjL5K7k-26K-C5wfArAruiYoXcyuXYCkTpbbc/edit?usp=sharing

## 功能

- 上傳 CSV、XLSX 或 ODS 檔案
- 以公開 Google Sheet 網址載入
- 依分頁預覽 YAML 並下載結果
- 介面支援英文／繁體中文
