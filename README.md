# HTML-Sheet2YAML

[English](./README.md) | [繁體中文](./README_zh_tw.md)

A lightweight, pure HTML tool for converting Google Sheets, ODS, XLSX, and CSV data into YAML—directly in your browser.

## Online Demo

https://pulipulichen.github.io/HTML-Sheet2YAML/

## Sample Google Sheet

Try the built-in **Try demo Google Sheet** button, or open this public spreadsheet:

https://docs.google.com/spreadsheets/d/1dOFyNqpjL5K7k-26K-C5wfArAruiYoXcyuXYCkTpbbc/edit?usp=sharing

## Features

- Upload CSV, XLSX, or ODS files
- Load a public Google Sheet URL
- Preview YAML per sheet and download results
- English / Traditional Chinese UI
